# Лабораторная работа №7

## Вариант 16 — Определение нажатой цифровой клавиши

### Условие задачи

Напишите программу, которая определяет, какая цифровая клавиша была нажата. Для ввода используйте `getch()`, объявленный в `conio.h`.

## Условие

Символ является цифрой, если он находится в диапазоне от `'0'` до `'9'`:

```c
(ch >= '0') && (ch <= '9')
```

## Алгоритм

1. Считать один символ с клавиатуры с помощью `getch()`.
2. Проверить, что символ больше или равен `'0'`.
3. Проверить, что символ меньше или равен `'9'`.
4. Если оба условия выполняются, вывести сообщение о том, что была нажата цифровая клавиша, и показать сам символ.
5. В противном случае вывести сообщение о том, что была нажата не цифровая клавиша.

## Код программы

```c

#include <stdio.h>
#include <conio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "RUS");
    char c;

    printf("Нажмите цифровую клавишу: ");

    c = _getch();

    switch (c)
    {
    case '0':
        printf("\nНажата клавиша 0\n");
        break;

    case '1':
        printf("\nНажата клавиша 1\n");
        break;

    case '2':
        printf("\nНажата клавиша 2\n");
        break;

    case '3':
        printf("\nНажата клавиша 3\n");
        break;

    case '4':
        printf("\nНажата клавиша 4\n");
        break;

    case '5':
        printf("\nНажата клавиша 5\n");
        break;

    case '6':
        printf("\nНажата клавиша 6\n");
        break;

    case '7':
        printf("\nНажата клавиша 7\n");
        break;

    case '8':
        printf("\nНажата клавиша 8\n");
        break;

    case '9':
        printf("\nНажата клавиша 9\n");
        break;

    default:
        printf("\nНажата не цифровая клавиша\n");
    }

    return 0;
}
```

## Проверка программы

### Пример 1

Нажата клавиша:

```text
7
```

Символ `'7'` входит в диапазон от `'0'` до `'9'`.

Результат:

```text
Была нажата цифровая клавиша: 7
```

### Пример 2

Нажата клавиша:

```text
A
```

Символ `'A'` не входит в диапазон от `'0'` до `'9'`.

Результат:

```text
Была нажата не цифровая клавиша
```
